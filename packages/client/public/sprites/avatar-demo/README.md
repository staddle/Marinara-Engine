# Example avatar

The example PNGTuber avatar in the avatar setup preview (Agent editor, 2D Avatars). It is never shown in chats.

Provenance: generated for Marinara Engine with Codex image generation on 2026-10-13. `base.png` came from a text prompt
(a cheerful cartoon chef, head and shoulders); `mouth-open.png`, `eyes-closed.png` and `eyes-closed-mouth-open.png`
were generated from `base.png` as a reference. Only their face area was then pasted onto `base.png`, so the pictures
line up exactly when the avatar blinks or talks. All four were resized to 384 × 384 and saved as palette PNGs.
